# Simple Tabs

Переключение вкладок с показом соответствующего контента на чистом JavaScript.

## Задача
Сверстать три вкладки («Профиль», «Настройки», «О нас») и блок контента:

- при клике на вкладку показывать соответствующий контент и подсвечивать активную вкладку;
- по умолчанию активна первая вкладка.

## Что реализовано
- Три вкладки в виде `<ul>` + `<li>` с атрибутом `data-tab`, задающим ключ.
- Блоки контента создаются из массива и вставляются в `#content`.
- Связь вкладки и её контента через **общий ключ** в `data-tab` — не по индексу и не по тексту.
- Переключение активного состояния вкладок и блоков контента через класс `.active`.
- Скрытие/показ контента через CSS: `#content > div { display: none }` + `#content > div.active { display: block }`.
- Делегирование клика: один обработчик на `#tabs` вместо отдельного на каждую вкладку.
- Единая функция `activeTab(key)` — снимает `.active` со всех, навешивает на нужные по ключу.
- Стартовая активная вкладка задаётся программно — без дублирования состояния в HTML.

## Технологии
- HTML
- CSS
- JavaScript
- Без фреймворков и библиотек.

## Как запустить
1. Скачать или клонировать репозиторий.
2. Открыть `index.html` в браузере.

## Структура проекта
```
├── index.html   — разметка: список вкладок и контейнер контента
├── index.css    — стили вкладок и правило скрытия/показа блоков
└── app.js       — массив контента, рендер, функция активации, обработчик клика
```
